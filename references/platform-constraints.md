# 平台图片合规约束（单一真理源）

> ecom-image2 的合规大脑。本文件是所有「图片能不能合法上架」判断的唯一来源——技术规范（Layer 1）+ AI 标注合规（Layer 2）+ 违规元素三层引擎（Layer 3）三层叠加。
> 定位：**技术预检与风险提示**。本文不能替代平台最新规则、律师意见或平台审核结果。
> 关联：生成后技术校验由 `scripts/compliance_check.py` 自动跑；AI 标注合规由 Claude 在 Step 7 读本文件做人工判断 + 生成清单卡。

## 合规三层模型

```
┌─────────────────────────────────────────────────────┐
│  Layer 1 技术规范（后置自动校验）                      │
│  主图白底 / 占比 / 无文字 / 尺寸 / 比例               │
│  → scripts/compliance_check.py 自动检测，出 JSON     │
├─────────────────────────────────────────────────────┤
│  Layer 2 AI 标注合规（前置分流 + 后置清单）            │
│  平台 toggle / 法规披露义务 / C2PA 隐形标记           │
│  → Claude 读本文件，生成「合规清单卡」给卖家照做      │
├─────────────────────────────────────────────────────┤
│  Layer 3 违规元素引擎（前置 prompt 扫描）              │
│  品类禁用元素 / 平台禁用 / 法规红线                   │
│  → Claude 在 Step 5/7 读本文件做人工判断              │
└─────────────────────────────────────────────────────┘
```

**核心准则（贯穿，不可越）**：
- 守住底线：复刻可识别真人 / 剥离 C2PA / 教唆规避 / 造假「100% 真人实拍」——主动拒绝。
- 底线之外：合规不是给卖家「加活」或「限图」，而是帮卖家用最小代价（后台勾选 + listing 文案 + 隐形标记）满足法规，画面零负担、转化率零损失。

## Layer 1：平台主图技术规范

> 生成后由 `scripts/compliance_check.py` 自动检测（白度 / 占比 / OCR）。脚本默认对 Amazon 主图最严格；其他平台用 `--platform` 切换阈值。

### Amazon（最严，电商主战场）

| 约束项 | 硬规则 | 检测方式 |
|---|---|---|
| 主图背景 | **纯白 RGB(255,255,255)** | 脚本：分割背景像素，判背景区是否接近纯白（产品大小不影响） |
| 产品占比 | **≥ 85%** 画面（产品应填充图片框的 85% 或以上） | 脚本：非背景像素占比 |
| 文字 / Logo / 水印 | **禁止**（主图不能含文字、Logo、水印、边框） | 脚本 OCR 扫描 |
| 比例 | 1:1（正方形） | imagegen.sh 尺寸校验 |
| 尺寸 | 最长边 ≥ 1000px（建议 ≥ 1600px 以支持 zoom） | imagegen.sh 尺寸校验 |
| 文件 | JPEG / TIFF / PNG（推荐 JPEG sRGB） | 不属本脚本范围 |
| 副图 | 允许文字、场景、对比（但不可加边框/渐变主图） | 仅主图受上表约束 |

**来源**：Amazon Seller Central「Product image requirements」。

### TikTok Shop

| 约束项 | 硬规则 |
|---|---|
| 主图背景 | 建议纯白或浅色干净背景（非强制纯白，但白底转化更高） |
| 主图文字 | 允许少量文字但建议极简（不可铺满/水印） |
| 比例 | 1:1（推荐）或 3:4 竖图 |
| 尺寸 | 最短边 ≥ 540px，推荐 ≥ 1080×1080 |
| AIGC 标注 | **强制**（2026-02-11 起）：AI 生成内容须开后台 `AIGC` toggle |
| 全合成主图 | 部分类目禁止「完全 AI 合成」作主图，需真实实物图 |

**来源**：TikTok Shop「Image requirements」+「AIGC content labeling policy」。

### Shopify

| 约束项 | 建议 |
|---|---|
| 主图背景 | 无平台强制，建议白底或场景统一（品牌自行决定） |
| 比例 | 1:1（推荐，theme 友好） |
| 尺寸 | 推荐 2048×2048（支持 zoom，文件 < 4477×4477） |
| 文字 | 无平台限制（品牌自定） |
| AIGC toggle | **平台不强制**，但若投 Google Shopping / Meta 广告则法规层强制披露 |
| ⚠️ 元数据坑 | Shopify 上传会**剥离 EXIF / IPTC / C2PA manifest** → 投 Google Shopping 撞「元数据剥离」违规。须在投 Google 前重新嵌 C2PA（用 `c2patool`） |

**来源**：Shopify Help Center「Image format and size」+ C2PA 跨平台互操作报告。

### 速卖通 / Temu（中国跨境平台）

| 约束项 | 硬规则 |
|---|---|
| 主图背景 | **纯白底**（AliExpress 标准/Temu 同） |
| 主图文字 | 禁止水印/边框/logo 铺满；允许极少角标（依类目） |
| 比例 | 1:1 |
| 尺寸 | 最短边 ≥ 800px，推荐 ≥ 1000×1000 |
| AIGC | 受中国《深度合成规定》约束：AI 生成内容须**隐形水印**（GB/T 45438-2025）+ 平台要求标注 |
| ⚠️ Temu 重复铺货 | Temu 三重检测（图/文/属性）→ AI 批量出图易触发「重复铺货」误判，套图须保持足够差异 |

**来源**：AliExpress「Image rules」+ Temu 卖家中心 + GB/T 45438-2025。

## Layer 2：AI 标注合规（平台 toggle + 法规）

> 披露位置、标签形式和机器可读凭证要求会随平台、市场和日期变化。生成前记录意图，发布前按目标平台官方后台与适用法律复核。
> 不同端点对 C2PA、SynthID 或其他来源凭证的支持不同。本项目不验证或补写这些凭证；如业务需要，必须按所用端点和目标平台的最新文档单独核验。

### 发布前动态复核

对 Amazon、TikTok Shop、Google Ads、Meta、Shopify、速卖通和 Temu，逐项查看当前发布页是否提供 AI 内容声明、人物合成声明或广告标签，并保存复核日期与官方页面链接。不要把本文中的历史界面描述当作当前规则。

涉及真人肖像、医疗/功效声称、受监管品类或多法域投放时，停止自动判断并交由具备相应资格的人审查。本文不维护罚款金额或生效日期，避免静态文档造成过期误导。

### 图类型 4 分类（前置分流，决定 toggle 强度）

Claude 在 Step 2.5（生成前）基于 prompt + 模板判断图类型——主信号是「生成意图」，比生成后 vision 检测可靠：

| 类型 | 典型场景 | 含 AI 人物 | 风险 | skill 动作 |
|---|---|---|---|---|
| **A 实拍感/无人物** | 实拍白底主图、AI 纯背景无人 | 否 | 低 | 保留 C2PA；提醒「加州/EU 8月后仍建议披露」 |
| **B 常规修图** | 实拍调色/裁剪/加字 | 否 | 最低 | 视为非 AI（但 GPT-Image-2 出的图仍带 C2PA） |
| **C 写实 AI 人物** | AI 模特/UGC/直播/试穿/手/背影/局部皮肤/群演 | 是 | **最高** | 强提醒「必勾两个框」+ 生成 disclosure 文案 |
| **D 复刻真人** | 拟复刻可识别名人/真人换脸 | 是 | **红线** | **主动拦截拒绝** |

**C 类触发词**（Claude 扫 prompt）：`model / person / human / hand / wrist / body / face / selfie / 模特 / 人物 / 手 / 背影`
**D 类拦截词**：`lookalike / 复刻 / celebrity / real person [具体人名] / 换脸 / face swap`
**C 但降级低风险**：含 `cartoon / stylized / mannequin(非写实) / 剪影 / abstract avatar` → 保留 prompt 记录作抗辩。

**律所边界解读**：AI 手/背影/局部皮肤/群演都触发纽约法披露；卡通化倾向不需要（intent matters，prompt 记录是关键）；亚马逊官方 AI 工具生成的图，法律责任仍由卖家承担。

### listing disclosure 文案库（多语言，卖家复制粘贴）

> C 类图生成后，Claude 从下表挑对应语言的文案给卖家贴进 listing 描述。一行字即合规。

| 语言 | 文案 |
|---|---|
| EN | Product images include AI-generated scenes and/or models. |
| DE | Die Produktbilder enthalten KI-generierte Szenen und/oder Modelle. |
| ZH | 本商品图片含 AI 生成场景/模特。 |
| JP | 本商品の画像には AI 生成のシーン/モデルが含まれます。 |
| ES | Las imágenes del producto incluyen escenas y/o modelos generados por IA. |
| FR | Les images du produit incluent des scènes et/ou des modèles générés par IA. |

### 合规清单卡模板（Step 7 输出，C 类示例）

```
📋 合规清单 — [图片名]
────────────────────────────────────────
图类型：C 类（含写实 AI 人物）　风险：高（纽约 SB 8420-A 直接适用）

✅ 你需要做的（都不用改图）：
[Amazon A+] 上传时勾选：☑ AI 生成  ☑ 含 AI 生成人物（无法跳过）

```

## Layer 3：违规元素三层引擎

> 「类目 × 违规元素」三层过滤。Claude 在 Step 5（组装 Constraints）和 Step 7（自检）读本表做人工判断；`compliance_check.py` 不做内容语义检测（OCR 只查「有没有文字」，不查「文字是什么意思」）。
> 每条表述为「检测什么 + 命中后建议什么」。

### 第 1 层：品类级禁用元素

> 生图 prompt 含下列品类 + 违规元素组合时，Claude 在 Step 5 注入 Constraints 拦截或改写。

| 品类 | 禁用元素 | 检测什么 | 命中后建议 |
|---|---|---|---|
| **食品 / 保健** | 医疗承诺文字 | prompt 含 `cure / treat / heal / 治疗 / 治愈 / 疗效 / 降糖 / 减肥` 等医疗断言 | 移除医疗词；改「支持消化」等结构功能词；提醒「FDA/食品安全标签须真实」 |
| **食品 / 保健** | 健康认证标志 | 图中出现 `FDA approved / CE / Organic certified` 等标志（无真实证书） | 移除标志；提醒「无真实认证不可画认证 logo」 |
| **电子产品** | 虚假认证标志 | 图中出现 `UL / CE / FCC / RoHS / ETL` 标志（除非卖家确认有证） | 默认不画认证 logo；除非卖家明确提供证书编号 |
| **电子产品** | 虚假规格参数 | 图上文字标 `10000W / 9999mAh` 等夸张参数 | 让卖家确认真实规格；用真实数字 |
| **美妆 / 个护** | 「速效」承诺 | prompt 含 `instant / 立刻 / 一抹就 / 7天美白` | 改为「helps improve appearance」类支持性表述 |
| **美妆 / 个护** | 医疗效果 | `祛疤 / 治愈 / anti-aging clinical proven`（无临床数据） | 移除医疗断言；保留外观性描述 |
| **医药 / 器械** | 处方药暗示 | 任何处方药包装 / 医生形象 / 注射器特写（非器械品类） | 拦截；提醒「处方药/器械受平台限售」 |
| **儿童用品** | 不安全使用场景 | 图中儿童无防护使用危险品 / 误食尺寸 | 改为安全使用场景；加成人监护提示 |
| **金融 / 虚拟商品** | 收益承诺 | `guaranteed return / 稳赚 / 月入十万` | 拦截（欺诈风险）；平台也禁 |
| **宠物用品** | 虐待暗示 | 项圈过紧 / 笼具过小 / 不适姿态 | 改为舒适使用场景 |

### 第 2 层：平台级禁用（主图通用）

> 与平台无关的「电商主图通用禁用」，对 Amazon 主图尤其硬。`compliance_check.py` 的 OCR 检测会抓「有无文字」，但具体是 Logo 还是水印需 Claude 判断。

| 违规 | 适用 | 检测 | 建议 |
|---|---|---|---|
| 文字 / 文案 | Amazon 主图、速卖通主图 | 脚本 OCR | 文字移到副图/A+ |
| Logo / 品牌标 | Amazon 主图 | OCR + Claude vision | 移到副图或包装图 |
| 水印 | 所有平台主图 | OCR + Claude vision | 移除（Amazon 直接拒） |
| 边框 / 装饰框 | Amazon 主图、TikTok 主图 | 脚本白度（边框会产生非白边缘） | 移除边框 |
| 渐变背景 | Amazon 主图（必须纯白） | 脚本白度（渐变 = 边缘不白） | 改纯白 RGB(255,255,255) |
| 多产品组合图 | Amazon 主图（须单件） | Claude vision | 拆成多张副图 |
| 模糊 / 低清 | 所有平台 | 脚本可扩展（当前不查分辨率） | imagegen.sh 尺寸校验已查 |
| 接触性暗示 | 所有平台 | Claude vision | 改构图 |

### 第 3 层：法规级红线（不可越，拦截级）

> 命中即**主动拒绝生成**或**强阻断**。这是 skill 守底线的最后一道闸。

| 违规 | 法规依据 | 检测 | 动作 |
|---|---|---|---|
| **复刻可识别真人** | 各州 right-of-publicity（伊利诺伊 HB 4875 等） | prompt 含 `lookalike / 复刻 / 某名人名 / 某具体真人参考图` | **拒绝生成**；提示「改用 AI 虚拟人（不对应真实自然人）」 |
| **剥离 C2PA / SynthID** | 来源透明与平台风险 | 用户请求「去除 AI 标记」 | **拒绝**；不协助规避来源披露或平台审核 |
| **教唆规避披露** | 来源透明与平台风险 | 用户问「怎么改一下不用标注」 | **拒绝**；不协助规避适用的披露义务或平台审核 |
| **造假「100% 真人实拍」** | 虚假陈述风险 | 用户要把 AI 图冒充实拍 | **拒绝**；不得把合成内容冒充真人实拍 |
| **政治广告 AI 深伪** | Meta / Google 政策 + 各州选举法 | 政治人物/选举相关 AI 图 | **拒绝**（skill 不做政治广告） |
| **商标 / 版权侵权** | DMCA / 各平台政策 | prompt 含明确第三方品牌名（`Nike swoosh / Apple logo` 等） | 拦截；提醒「须有授权或改通用设计」 |
| **危险品美化** | 平台禁售清单 | 美化毒品/武器/违禁品使用场景 | **拒绝** |

## 跨平台叠加规则

一张图分发多平台/多市场时，按 `max(各约束)` 执行：

```
最终约束 = max(Layer 1 各平台技术规范)
         + max(Layer 2 各平台 toggle ∪ 各市场法规)
         + Layer 3 全部红线（不可降级）
```

**示例**：
- 图要同时发 Amazon + Shopify + 投 Google → 按 **Amazon 纯白底** + **Google Ads AI 标签** + **Shopify 元数据重嵌提醒** 叠加。
- 含 AI 模特 + 多市场分发 → 分别复核各目标市场的现行规则，并执行其中更严格且适用的要求。

**简化原则**：除非用户明确说「只发 X 平台」，否则默认 Amazon 基线（最严技术规范）+ 目标市场法规叠加。

## 脚本自动化 vs 人工判断的边界

| 能力 | 谁做 | 备注 |
|---|---|---|
| 背景白度检测 | `compliance_check.py` 自动 | 分割背景像素（与边缘主色接近的像素），判背景区是否接近纯白；产品大小不影响判定 |
| 前景占比检测 | `compliance_check.py` 自动 | 非背景像素占比（有阴影/渐变时偏保守，当前只告警不阻断） |
| 主图有无文字 | `compliance_check.py` 自动（OCR，需 tesseract） | 无 tesseract 则降级跳过，Claude 用 vision 补 |
| 文字语义（医疗承诺/虚假参数） | Claude 人工 | 脚本不判语义 |
| Logo / 水印识别 | Claude vision | OCR 只测「有字」，是否 Logo 需判断 |
| AI 人物识别 | Claude（基于 prompt + 图） | 脚本不做 |
| 真人复刻拦截 | Claude（基于 prompt） | 脚本不做，但 Claude 必须拦 |
| C2PA manifest 检测 | `c2patool`（后续） | 本脚本不查 |
| 后台 toggle 清单生成 | Claude（读 Layer 2） | 脚本不生成文案 |

**纪律**：脚本只做「告警」非「阻断」（当前积累真实数据再调阈值）。Claude 拿到脚本 JSON 后，结合本文件做综合判断，不机械依赖单一指标。
