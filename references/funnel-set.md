## 一、转化漏斗槽位全景

电商 Listing 套图按买家旅程分 **6 层 9 槽位**。其中 **7 个核心槽位**是 Listing 标配（覆盖亚马逊主图位 1-7），**2 个扩展槽位**用于品牌进阶（信任/忠诚层）。

### 核心槽位（7，Listing 必备）

| # | 漏斗层 | 槽位 | 目的 | 推荐场景模板 | 该槽位 Campaign Lock 注意点 |
|---|---|---|---|---|---|
| 1 | **认知** | 主图（吸睛） | 搜索结果页第一眼抓住注意力，决定点击率 | `hero-image.json` | 产品呈现规则锁死（角度/占比）；Amazon 主图背景强制 `#FFFFFF` 纯白、无文字、占比≥85%（见 `platform-constraints.md`） |
| 2 | **认知** | 场景图（代入） | 让买家想象"我用它的样子"，建立使用情境 | `lifestyle-scene.json` | 背景系统允许从纯白切到质感底（但仍属 Lock 的 background_system 范围）；模特肤色按 region 锁（见 Lock 第六节 6.2） |
| 3 | **考虑** | 卖点信息图 | 用图标+短文案讲清 3-6 个核心卖点 | `infographic.json` | 图标系统锁死（风格/线宽/圆角）；字体系统锁死；布局网格锁死；短文案是单张自由度可改 |
| 4 | **考虑** | 细节图 | 展示材质/工艺/微观质感，打消品质疑虑 | `detail-macro.json` | 光线系统锁死（微距对光线敏感，漂移会显假）；产品呈现规则中的裁切规则可在此槽放宽（允许 edge crop） |
| 5 | **评估** | 对比图 | 与竞品/旧版/使用前后对比，突出优势 | `before-after.json` | 色板锁死（对比图最易色彩漂移，竞品用灰色中性化处理避免抢色）；布局系统的对齐规则锁死（左右/上下分栏比例固定） |
| 6 | **评估** | 规格尺寸图 | 标注尺寸/容量/重量/兼容性，降低退货 | `size-spec.json` | 字体系统锁死（标注字体必须统一）；图标系统锁死（尺寸箭头/标尺样式）；布局网格锁死（标注线对齐规则） |
| 7 | **转化** | 包装/赠品图 | 展示包装质感/赠品组合，提升"值不值"感知 | `packaging.json` | 背景系统锁死（包装图背景与主图同语言）；产品呈现规则锁死（包装与产品的比例关系）；如含赠品组合，用 `multi-product.json` 补充 |

### 扩展槽位（2，品牌进阶可选）

| # | 漏斗层 | 槽位 | 目的 | 推荐场景模板 | 该槽位 Campaign Lock 注意点 |
|---|---|---|---|---|---|
| 8 | **信任** | UGC/认证图 | 真实买家秀/权威认证，打消最后顾虑 | `ugc-style.json` | **反 AI 感优先于 Lock 一致性**：UGC 允许光线/背景轻微"去精致化"（见 SKILL.md Anti-AI 规则）；但色板和字体仍锁。认证图（如有 ISO/FDA badge）用 `icon_system` 统一徽章风格 |
| 9 | **忠诚** | 品牌故事图 | 传递品牌理念/创始人/工艺故事，建立长期心智 | `magazine-editorial.json` 或 `creative-concept.json` | 允许最宽的自由度：画面目的+主体动作+局部构图+短文案四项全开放；但色板和字体仍锁（否则脱离品牌识别）。适合用 `editorial illustration` 视觉方向 |

> **7 vs 9 怎么选**：默认交付核心 7 槽位（Listing 标配）。用户明确要"品牌升级/讲故事/A+ 品牌模块"时加扩展槽位 8-9。不要硬塞 9 张——信任/忠诚层图质量不够反而拉低转化。

## 二、驱动力 → 槽位优先级（对接 Step 3）

Step 3 诊断出三类驱动力，决定套图的槽位编排重心：

| 驱动力 | 核心槽位（必做，重投入） | 次要槽位（选做） | 编排逻辑 |
|---|---|---|---|
| **视觉驱动**（颜值/设计感） | 1 主图、2 场景图、4 细节图 | 3 卖点信息图、7 包装图 | 用"美"打动，主图+场景+细节三张要把材质光影渲染到极致；卖点图次要（产品自己会说话） |
| **痛点驱动**（解决具体问题） | 1 主图、3 卖点信息图、5 对比图 | 2 场景图、6 规格尺寸图 | 主图直击痛点，信息图讲清"怎么解决"，对比图证明"比替代方案好"；场景图次要（买家关心功能不关心氛围） |
| **情感驱动**（氛围/故事） | 1 主图、2 场景图、9 品牌故事图 | 7 包装图、8 UGC 图 | 主图+场景+故事三张构建情绪；功能图（3/5/6）弱化甚至省略；扩展槽位 9 几乎必做 |

> 驱动力诊断只影响"哪几张重投入、哪几张可选"，不影响 Lock 本身（Lock 是整套统一的，不分槽位）。

## 三、生成顺序与编排建议

### 3.0 两条编排路线：精细模式 vs 快速通道

套图任务有两条生成路线，按用户诉求选：

| | **精细模式（本文件 3.1-3.5，默认推荐）** | **快速通道（单 prompt 整套）** |
|---|---|---|
| 机制 | 逐槽位编排，Campaign Lock 逐张锁定，每张可独立精修 | 一条 prompt 让模型自己产整套（白底/卖点/尺寸/多角度/场景/细节） |
| 控制度 | 高——每张图的角度/光线/文案都可控 | 低——版式由模型决定，一致性靠单次生成的天然连贯 |
| 成本/速度 | 多次调用，慢而精 | 一次调用，快而糙 |
| 适用 | 正式 Listing 上架、质量敏感 | 冷启动看方向、草稿期探索、预算极紧 |

**快速通道 prompt 骨架**（社区验证的 Marketplace Listing Image Set 配方）：

```
Generate a {platform} listing image set for {country} in {language}.
The product is {product_name}, and the selling points are {selling_points}.
```

平台词已验证覆盖：Amazon / eBay / AliExpress / TEMU / SHEIN / TikTok Shop / Shopee / Lazada / Mercado Libre / Walmart / Etsy / Rakuten / Coupang / Shopify；语言可指定（18 语种验证过，含阿/日/韩/德/西/法等）。

**取舍规则**：快速通道出完的套图，若用户对其中 2-3 张不满意 → 切回精细模式只重做那几张（prepend 从满意图中提炼的 Lock）——两条路线可混用，不是二选一。

### 3.1 标准生成顺序（精细模式，推荐）

Claude 编排套图时按此顺序生成，每张图都 prepend 同一段 Lock：

```
1. 主图          ← 先出主图，锁定产品呈现规则（后续图以此为锚）
2. 场景图        ← 验证背景系统在非纯白下的表现
3. 卖点信息图     ← 验证图标/字体系统
4. 细节图        ← 验证光线系统在微距下的一致性
5. 对比图        ← 验证色板在多元素场景下的稳定性
6. 规格尺寸图     ← 验证布局网格的标注对齐
7. 包装图        ← 收尾，验证整体视觉语言闭环
（扩展）8. UGC 图 / 9. 品牌故事图
```

**为什么主图优先**：主图锁定产品的"锚点外观"（角度/光线/占比）。后续每张图都以主图的产品呈现为基准，漂移最容易在第一张到第二张之间发生——主图先定调，后续 prepend Lock 时有具体参照。

### 3.2 多变体套图的顺序（颜色/材质变体）

多变体（如 4 色耳机）不按漏斗槽位编，按**锚点+变体**编：

```
1. 先出 1 张主图（选定一个颜色的"基准变体"）→ 锁定全套 Lock
2. 用同一 Lock + 同一锚点，n=4 批量出 4 色变体（只改 Subject 的 color/material）
3. （可选）每个变体再各出 1 张场景图，共用同一场景 Lock
```

> 多变体的 Lock 规则见 `campaign-style-lock.md` 第四节。核心：同锚点同光线同角度，只改颜色材质。

### 3.3 套图规模建议

| 用户请求 | 建议交付 | 说明 |
|---|---|---|
| "做一套 Listing 套图"（未指定数） | 核心 7 槽位 | Listing 标配，覆盖全漏斗 |
| "做 3 张图" | 主图 + 场景图 + 卖点信息图 | 最小可用集（认知+考虑） |
| "做 5 张图" | 主图 + 场景图 + 卖点信息图 + 对比图 + 包装图 | 高转化五件套（认知+考虑+评估+转化） |
| "做 A+ 内容" | 卖点信息图 + 规格尺寸图 + 品牌故事图（槽位 3/6/9） | A+ 模块对应，尺寸按 `platform-constraints.md` |
| "做变体套图" | 1 主图 + N 个颜色变体 | 见 3.2 多变体规则 |

## 四、region 对槽位权重的影响

region 主要影响 Lock 字段（见 `campaign-style-lock.md` 第六节），但也会微调槽位编排。下表是编排层的 region 调整，**不重复 Lock 层的色板/字体调整**：

| region | 槽位权重调整 | 编排建议 |
|---|---|---|
| **US** | 主图 + 卖点信息图 + 对比图权重高 | 美国买家重卖点直给，3/5 槽位必做且重投入；场景图可适度 |
| **EU** | 场景图 + 细节图 + 品牌故事图权重高 | 欧洲买家重质感与品牌调性，2/4/9 槽位重投入；信息图克制（不堆卖点） |
| **SEA** | 主图 + 卖点信息图 + 包装图权重高 | 东南亚买家重促销感与性价比，1/3/7 槽位突出优惠；可加节日元素（见 Lock 6.4） |
| **CN** | 卖点信息图 + 规格尺寸图 + 对比图权重高 | 中国买家重参数与口碑，3/5/6 槽位详尽；场景图偏精致国潮可选 |
| **ME** | 场景图 + 包装图 + 品牌故事图权重高 | 中东买家重尊贵感与包装礼赠，2/7/9 重投入；信息图用阿语排版（字体见 Lock 6.1）；禁忌图（含猪/酒精/暴露）整槽替换或删除 |

> region 的 Lock 层调整（色板/字体/肤色/禁忌/节日）一律查 `campaign-style-lock.md` 第六节，本表只管"该 region 多放哪几张图"。

## 五、套图任务编排清单（Claude 决策流程）

Claude 接到套图任务后，按此清单决策（读完本节即可直接编排，无需回看其他章节）：

```
1. 确认套图规模
   ├─ 用户指定张数 → 按第三节 3.3 建议映射到槽位
   └─ 未指定 → 默认核心 7 槽位

2. 诊断驱动力（Step 3 已做）
   ├─ 视觉驱动 → 重投入槽位 1/2/4
   ├─ 痛点驱动 → 重投入槽位 1/3/5
   └─ 情感驱动 → 重投入槽位 1/2/9

3. 查 region 调整（第四节）
   └─ 按 region 微调槽位权重（US 重卖点 / EU 重质感 / SEA 重促销 ...）

4. 建 Campaign Lock（读 campaign-style-lock.md）
   ├─ 有品牌规范 → 基于品牌填 10 字段
   └─ 无品牌规范 → 读 assets/default-style-lock.json + 品类/region 覆盖

5. 按标准顺序生成（第三节 3.1）
   └─ 每张图 prepend 同一段 Lock，只改 4 项自由度（画面目的/主体动作/局部构图/短文案）

6. 套图一致性自检（Step 7）
   ├─ 色板/字体/光线/背景是否跨图漂移
   ├─ 产品角度是否一致
   └─ region 禁忌是否触发（Lock 6.3）
```
